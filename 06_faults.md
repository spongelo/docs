# Faults and Maintenance

## Reporting a fault

- A user or the system can report a machine fault through the queue site.
- Once a fault is reported, the machine is marked out of order and cannot be selected or used until it is usable again.

## Manager responsibility

The system manager reviews the problem and decides whether the machine needs maintenance or replacement. After the issue is resolved, the manager clears the out-of-order status so the machine can return to service.

## Unspecified

The process for manager review, repair records, and any physical out-of-order sign has not been specified.
