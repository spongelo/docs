# Hardware and Sensing

## Cycle start

After the user loads laundry and presses the machine's start control, a hardware signal indicates that the cycle has started.

## Cycle completion

- A built-in signal from the machine indicates that the cycle is complete after a certain amount of water has been cycled.
- The machine provides the completion signal; the queue system does not calculate a water threshold.
- The signal's technical format and how it connects to the queue site have not been specified.

## Laundry presence

A weight sensor indicates whether laundry remains inside the machine. This sensor reports laundry presence separately from cycle completion and does not control when the machine becomes available.
