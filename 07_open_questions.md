# Open Questions

The following details are not yet decided in the overview:

## Registration and queue

- Can users cancel registration or leave the waiting queue? If so, how does that affect their queue number and place?
- How does a user claim a machine during the 10-minute window?
- If a claim expires and there is nobody else waiting, what happens to the person who missed the claim?
- How are queue numbers handled if a registration is cancelled or a user registers more than once in a day?

## Machine signals and page behavior

- What hardware interface connects machine start and completion signals and the weight sensor to the queue site?
- Which device produces the queue-page beep, and how is the waiting user expected to receive it?
- What should happen if a signal or sensor is unavailable or incorrect?

## Fault handling

- What review process does the system manager use to decide between maintenance and replacement?
- Is a physical out-of-order sign required in addition to the queue site's status?
