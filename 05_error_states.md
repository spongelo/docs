# Queue Page and Notifications

## Queue page

The page provides a view of the six machines and the waiting queue. It shows:

- Machine labels 1–6 and whether each machine is available, in use, or out of order.
- The name and queue number of each person using a machine or waiting.
- Whether laundry remains in a machine after its cycle, as indicated by the weight sensor.

The page updates machine availability and queue status when a cycle completes or a machine otherwise becomes available.

## Beeps

- At cycle completion, the machine beeps to alert the current user.
- The queue page/device also beeps to alert the current user and the next person waiting.
- When a machine becomes available for a waiting person, the next person is notified and has 10 minutes to claim it.

The exact device, delivery mechanism, and behavior when a user cannot hear or receive a beep have not been specified.
